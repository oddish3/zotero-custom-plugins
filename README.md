# Personal Zotero plugins

Packages for Zotero 10.0.x.

Releases contain Zotero TLDR and Supplement PDF, update metadata, source files, and validation notes. TLDR derives from [syt2/Zotero-TLDR](https://github.com/syt2/Zotero-TLDR) under AGPL-3.0-or-later.

Install XPI files through Zotero Tools → Plugins → Install Plugin From File. Older personal installations need one manual update to adopt this update source.

This repository contains no Zotero profiles or library data.
